# my-VPN

## Description

A personal VPN tool that provisions an OpenVPN server on AWS in seconds. Uses Terraform to create infrastructure and Ansible to configure OpenVPN. Costs ~$1/year (t2.micro EC2).

## Prerequisites

- AWS CLI (configured with your account)
- Terraform
- Ansible
- OpenVPN client

## Setup

1. Configure AWS CLI with your account credentials.
2. For each new region, import the default subnet into its Terraform workspace before first use:
   ```bash
   cd terraform/
   terraform workspace new <region>        # e.g. eu-central-1
   terraform import aws_default_subnet.public_subnet1 <SubnetID>
   ```

## Usage

### Start VPN

```bash
./setup.sh start --region <aws-region>   # e.g. eu-central-1, us-east-1
```

Only one VPN can run at a time. The SSH key (`myKey.pem`) is auto-generated by Terraform on first use in a region.

### Connect to VPN

1. Open your OpenVPN client.
2. Import `clients/my-client.ovpn` (auto-fetched after provisioning).
3. Connect and enjoy.

### Stop VPN

```bash
./setup.sh stop
```

Auto-detects the active region — no arguments needed.

## Multi-Region Support

Each AWS region gets its own Terraform workspace, so infrastructure state is tracked independently. Only the EC2 instance is destroyed on stop; the subnet import and key pair persist in the workspace for faster future starts.

## Limitations

- Bandwidth is limited on t2.micro — expect modest speeds.
- You get what you pay for.
